# LabAssistAgent

LabAssistAgent is a tool designed to assist with laboratory tasks by leveraging modern technologies such as Streamlit for the user interface, ChromaDB for database management, and LangChain for natural language processing and text manipulation.

## Features
- Interactive user interface built with Streamlit.
- Integration with ChromaDB for efficient data storage and retrieval.
- PDF processing capabilities using PyPDF.
- Advanced text processing and natural language understanding powered by LangChain.

## Requirements
Ensure you have the following dependencies installed. You can find the required versions in the `requirement.txt` file:
- Streamlit
- ChromaDB
- PyPDF
- LangChain and its related modules

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd LabAssistAgent
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirement.txt
   ```

## Usage
1. Run the application:
   ```bash
   streamlit run app.py
   ```

2. Follow the instructions on the Streamlit interface to interact with the tool.
